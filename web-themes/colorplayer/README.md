# Color Player

将解压后的 `color-player` 文件夹放在 FluentFlyout 的 `web-theme` 下，选中该主题，再将 FluentFlyout 提供的主题地址用于 OBS 浏览器源。双击 `index.html` 可预览待机画面和选色器。实时媒体数据由 FluentFlyout 提供。

参考画布为 393 × 415。页面按可用宽高等比居中，画布以外透明。OBS 可设置为 393 × 415 或 786 × 830。场景名中的 `[dark]` 和 `[light]` 控制两部分的配色。

- `scripts/player.js` 管理媒体订阅、封面、文字滚动和播放进度动画。
- `scripts/color-picker.js` 管理色环自动旋转、亮度及三角形选色。拖动结束后两秒恢复旋转。
- `scripts/layout.js` 负责整体缩放和 OBS 场景主题。
- `styles/` 中的同名样式表分别控制播放器、选色器和共享布局。

B 栏的渐变属于选色器，拖动可调整预览色的亮度。其上方的白色滑块与右侧百分比显示歌曲进度。点击右下角加号打开设置菜单，可开启「色环随音乐播放启停」。默认关闭，选择会保存在当前浏览器中。开启后，仅在音乐播放时自动旋转；暂停、停止或断线时保持当前角度。
